# 近两个月量价、压力与止损参考

入口：新生成日报/周报的个股事实中，“近两个月量价 · 压力与止损参考”。方法标识 `PRICE_VOLUME_2M_V3`。本功能研究单只自选，不依赖完整全A评级，也不读取个人成本或给出仓位比例。

## 窗口与价格口径

- 窗口是业务截止日减两个自然月至截止日，包含边界，不把60个交易日称为两个月。
- 至少30根有效日K。冻结按上市日期、权威日历和同源明确停牌核对的应有日期；缺少任一天、混合来源、无因子、无有效OHLC或量、业务日没有行情时，保留缺项，不给当前价位与减仓意见。
- `价格 = 原价 × 当期因子 / 截止日因子`。量能统一使用原始人民币成交额；价格因子包含现金分红等事件，不能直接当作股本变化因子。原始股数仍验证有效，但不使用价格因子调整它或据此判断放量。
- 参考位只使用截止日前的历史K线，截止日用于判断是否触及或突破。未来价格不参与；当日急跌不能通过纳入当日新低来重新降低原止损参考。

## 参考位怎样形成

| 内容         | 固定方法                                                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| 结构支撑     | 最近20根历史K线中最近一个已确认波谷；确认需要左右各2根K线。没有波谷时用前20期最低价                                                     |
| 支撑区间宽度 | 支撑中心上下各 `max(0.01元, 前收盘价×0.5%, ATR14×0.25)`                                                                                 |
| ATR14        | 截止日前14期真实波幅的简单均值；真实波幅为当期高低差、最高与前收差绝对值、最低与前收差绝对值三者最大值                                  |
| 止损参考     | 原结构支撑下沿减 `0.5×ATR14`；无法形成正数参考时为空。触及/跌破直接显示，不强行把价格移到现价下方                                       |
| 压力候选     | 已确认波峰、此前两月最高价、前三个日K近似成交额价桶。只保留现价上方或覆盖现价上沿的候选，重叠去重后最多3个，按距离排序                  |
| 日K近似价桶  | 将此前每根日K的 `(最高+最低+收盘)/3` 放入宽度 `max(0.01元, 截止日收盘价×1%, ATR14/2)` 的价格桶，以原始人民币成交额累加；按成交额取前3桶 |

日K价桶不是逐笔成交分布，不代表实际筹码成本、机构持仓或真实供给墙。若收盘达到或突破此前两月最高价，压力列表留空，不外推更高目标价。原支撑已失守时仍保留原区间，并明确标注。

## 减仓观察意见

两个量比定义不同，页面分别展示：当日量比为当日成交额除以前20期平均成交额；5日量比为最近5期平均成交额除以此前独立20期平均成交额，两窗口不重叠。5日收益使用当前收盘与5个交易日前收盘比较。

按下表从上到下判断，先满足者优先：

| 状态                     | 条件                                                                                         | 展示意见                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| REDUCE_REVIEW            | 收盘触及/跌破止损参考                                                                        | 优先评估减仓控制风险                                     |
| REDUCE_REVIEW            | 当日下跌且当日成交额量比≥1.2并跌破原支撑下沿；或5日收益≤−2%、5日成交额量比≥1.2且收盘低于MA20 | 放量走弱，已有持仓可考虑减仓并核对收复情况               |
| PROFIT_PROTECTION_REVIEW | 距压力下沿不超过2%且不高于压力上沿，5日收益≥2%，5日成交额量比≤0.8                            | 反弹遇压但量能收缩，可评估分批减仓；放量突破后重评       |
| WATCH_REDUCTION          | 原支撑失守；或5日收益≤−2%且低于MA20，但未满足以上确认条件                                    | 关注减仓条件；缩量下跌不代表风险已解除                   |
| OBSERVE                  | 其他有效输入                                                                                 | 尚无明确减仓组合，继续观察；不是买入信号或必须持有的结论 |
| UNAVAILABLE              | 停牌、陈旧、演示或证据不足                                                                   | 暂不判断，列出实际缺项                                   |

这些是公开、固定的研究假设，尚未证明历史预测或收益效果。没有个人成本、资金需求、风险承受度时，不计算减仓数量或比例。止损状态按本期收盘确认，不代表盘中从未穿越；界面同时显示参考位相对本期收盘的距离。结构参考不等于个人可承担亏损，不应直接替代原有交易计划。止损参考不是委托保证成交价；跳空、涨跌停和交易制度可能影响执行。

## 冻结、兼容与实现

新报告的 `input_snapshot.priceVolumeMethod` 保存方法标识，每只股票保存 `expectedTradingDates`，实际结果写入 `analysis.priceVolume`。仍使用既有报告JSON存储，不新增表或第二份 SQL。

旧报告没有该字段时继续读取原冻结内容，不调用最新行情补算；界面提示生成新修订。新方法随 `REPORT_V11 / PIPELINE_V14 / FROZEN_FACTS_V8` 发布，技术规则 `RULE_V2` 和指标算法未改变。

实现入口：[PriceVolumeCalculator](../../backend/src/main/java/com/alphascope/intelligence/calculator/PriceVolumeCalculator.java)、[冻结适配](../../backend/src/main/java/com/alphascope/intelligence/builder/PriceVolumeAnalysisBuilder.java)、[响应定义](../../backend/src/main/java/com/alphascope/intelligence/vo/PriceVolumeStudy.java)。

一般概念参考：[Fidelity 支撑与压力](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/support-and-resistance)、[Investor.gov 止损价格与执行价格](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-14)。本项目的具体窗口、参数和决策组合自行定义，不声称这些来源认可其效果。

当前方法保留 `volumeBasis=TURNOVER_AMOUNT`。V1旧代理量、V2成交额研究均只读取已冻结内容，不追加V3仓位策略。新策略字段为空的历史修订，界面提示生成新修订；旧价位仍可用红色强调，样式不改变原证据。

## 条件式建仓、加仓和减仓

新增 `analysis.priceVolume[].strategies`，方法为 `POSITION_RESEARCH_V1`。策略来自同一份冻结量价事实，不读取个人是否持仓，不能把“未触发减仓”推导成“可以买入”。所有价位在“关键价位速览”和详情中统一红色强调，颜色不代表条件已触发。

| 方案               | 参考与全部行情条件                                                                                                                                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 回踩企稳建仓       | 使用原支撑上沿；本期最低触及该上沿，收盘收复并不高于上沿+2%；当日收益≥0，成交额量比≤1；通过共用趋势与风险过滤                                               |
| 放量突破建仓       | 压力参考只使用前一交易日及以前的资料；前收≤原压力上沿，本期收盘>上沿；当日收益>0、成交额量比≥1.2；最高追价上限为原上沿+3%                                   |
| 突破确认后回踩加仓 | 参考区间在最近两个确认交易日之前已经形成；前收及本期收盘均站在其上沿之上，本期最低回踩至上沿+2%以内，收盘不超过上沿+3%；当日收益≥0、当日及5日成交额量比均≥1 |
| 减仓与风险退出     | 沿用量价减仓的三个风险组合：收盘触及止损、放量走弱、缩量反弹遇压；任一触发即进入复核，不要求三个组合同时成立                                                |

建仓与加仓共用过滤：本期收盘≥MA20；盘中最低未触及结构止损；未触发明确减仓或遇压保护组合；候选观察带上沿到结构止损的距离须>0且≤8%。这8%只是未验证的技术过滤线，不是个人账户风险预算，也不保证最大损失。

候选带下沿为原参考区上沿，上沿同时受2%/3%价差及 `止损参考÷(1−8%)` 限制，报价向下舍入到两位小数。若风险上限低于候选下沿，则保留原带并明确风险拦截，不降低止损来凑条件。只有实际收盘也处于最终观察带内时，才可能判定行情条件满足。

状态分别为：`CONDITIONAL_MATCH` 行情条件满足但个人前提尚待核验；`WAIT` 等待；`WATCH` 复核减仓；`RISK_BLOCKED` 风险过滤；`UNAVAILABLE` 资料不足。每条条件保留 observed、required 和 met；met为空是待核验，不等于未触发。建仓/加仓使用ALL，减仓使用ANY，界面不能混用。

已触发减仓条件会优先阻止新建/加仓。加仓仅适用于已持有且原逻辑未失效、仍有个人风险额度的情形，不用于下跌摊薄成本；系统并未确认用户具备这些个人前提。各方案保存失效条件，不给数量或比例，也不触发券商委托。参数未经历史效果验证。

实现：[策略纯计算](../../backend/src/main/java/com/alphascope/intelligence/calculator/PositionStrategyCalculator.java)、[输入对象](../../backend/src/main/java/com/alphascope/intelligence/dto/PositionStrategyInput.java)、[策略及条件响应](../../backend/src/main/java/com/alphascope/intelligence/vo/PositionStrategy.java)。

主量价计算的止损、放量走弱和缩量反弹遇压判定只计算一次，策略复用其布尔结果，不以页面舍入数值重复推导减仓结论。资料未知单独显示“待核验”，不能当作未触发风险。
