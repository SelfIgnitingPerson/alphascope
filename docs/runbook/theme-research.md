# 同业联动与研究建议

本功能服务于自选研究。它把已观察事实、待验证解释、后续核查和调整判断的条件分别保存，不产生个人仓位建议或交易指令。

## 当前龙头与历史样本

AI产业链现在先展示当前核心企业目录：光互联以中际旭创、新易盛、天孚通信为核心组；PCB区分制造与覆铜板；设备区分平台、刻蚀、清洗；存储区分芯片设计、内存接口、模组。目录由`backend/src/main/resources/research/theme-leaders.json`集中管理，每组保留核对日期、选择依据、企业产业角色和逐项原始来源。展示序是基于业务地位的研究优先序，不能包装成统一全球名次或买入排名；市场简称“易中天”也不表示三家均为光模块厂商第一至第三。

只有`formalRanking`中明确注明年份与范围的名次才是原始来源排名，例如深南电路的全球PCB营收规模、生益科技的刚性覆铜板销售额，不能跨子行业或年份比较。当前目录不倒填到更早研究日期，页面会标明后来核对日期；不自动加入个人自选，不写入历史披露成分表，不改变主题强弱或旧报告。

原有披露样本与联动观察收纳在独立折叠区，仍保留原成员、日期和输入指纹。核心企业目录只读接口为`GET /api/v1/themes/leaders`和`GET /api/v1/themes/{code}/leaders`，不会发起行情采集。修改当前核心目录无需改历史样本定义；如要改变参与计算的成员，仍须按下述来源和新样本版本流程处理。

## 采集与连续三日规则

真实每日任务先执行 `THEME_MEMBERS`，再采集样本行情：自选与沪深300取两年，同业新增标的取六个月。使用真实交易日历计算指标，并重算最近10个自然日内的实际交易日评分。行情请求失败保留任务错误，不制造替代数据。

主题分化要求同一主题、同一样本版本、最近三个实际交易日每天均满足至少两只有效成员和配置的最低覆盖率。收益与广度缺日、旧版本评分或单成员不满足条件。旧手工归属仍保留2026-10-30生效日期；新的披露样本使用独立表与其真实来源可用日期。

## 20日、60日联动

1. 个股与同业使用各自同源原价乘真实复权因子，按交易日精确对齐。计算N日需要N+1个收盘点，不跨缺失日期计算，不填0、不混接来源。
2. 同业组合排除被研究个股自身，至少两只完整同业、名单覆盖率至少80%。每日同业收益等权平均，再复合成区间组合收益；个股区间收益减组合收益得到相对收益差。
3. 展示20日与60日Pearson日收益相关系数。零方差或历史不足显示缺失，不强行记为0。
4. 同时展示将双方收益分别对沪深300收益做含截距OLS后，残差之间的60日相关系数。它只控制选定市场因子的线性影响，不证明因果或领先关系。
5. 0.6相关线和落后5个百分点为可读解释采用的启发式观察线，尚未验证预测效果。与风险规则的阈值分别管理；后者完整冻结在报告 `ruleParameters` 中。

## 如何理解建议

“优先核查”表示趋势、利润、毛利率或现金流证据值得先复核。建议引用实际数据和本次冻结阈值，并列出同口径财报、成本费用、动态均线、未来3个交易日相对同业表现等核对项目。可能的产品结构、成本或市场资金解释会明确标记待验证，不把相关性写成原因。

连续两日回到动态MA20且均线不再下降等是调整研究判断的观察条件，并非已经验证有效的入场策略；报告不设固定买卖价，不保证收益。

## “量子纠缠”类比

产品中的“量子纠缠”仅为同业联动的类比，不引用未经核对的帖子观点。[诺贝尔物理学奖官方说明](https://www.nobelprize.org/prizes/physics/2022/press-release/)讨论的是物理量子态、贝尔不等式和量子信息实验。

股票共同涨跌可用共同市场因子、产业暴露等经典统计关系研究。这里仅借“联动与分化”作类比，实际计算Pearson相关和OLS残差相关；没有测量股票的物理量子纠缠，也不能由物理理论推出次日价格。页面同时显示样本来源、统计窗口和这些限制。

## 报告追溯

当前报告冻结样本来源与成员、行情、日历、三日评分、规则阈值和分析结果。读取旧报告不查询当前成员重建历史。数据库结构见[数据字典](../database/schema.md)。

## 仅补建主题观察

`bash scripts/tools.sh sync-theme-research YYYY-MM-DD`用于LOCAL真实模式维护：无活动研究和验证任务时，先核对交易日历及沪深300，再登记业务日已公开的样本、串行补齐140个自然日的成员同源行情，并计算技术指标与最近实际交易日主题观察。此命令关闭自身后台工作线程、定时器和自动备份，不改个人自选、不生成报告；原有每日任务仍会自动执行相同目录的登记和后续更新。

单个成员失败会保留受控诊断并继续核对其他成员，最终明确失败，不伪造替代行情或提高覆盖率。数据来源的访问保护、许可、冷却、预算和同源要求全部沿用现有路由。未知完整行业覆盖仍为UNKNOWN；原始公开资料的可用日期与本次实际核验时间分别保存，不能将事后选样写成已经通过严格历史效果验证。

## 维护当前核心目录

主题详情的管理员“维护当前核心企业目录”可调整公司、业务角色、展示顺序与原始依据。保存时需重新核对资料，核对日期只能是上海当前日；来源须为有标题、不含用户凭据的HTTPS链接。写事务先锁主题，检查页面预期修订，冲突返回409并要求刷新，避免覆盖他人修改。

每次维护追加不可变theme_leader_revision及SHA256，不覆盖源码初始目录、过去修订、披露成分或报告。公共目录展示最近维护版本；历史日期仍提示是后来整理的当前资料。距核对超过90天时提醒重新复核，不自动改变梯队或倒填成分日期。
