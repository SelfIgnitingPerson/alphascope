# 五维规则研究评分

当前方法MARKET_RULES_V3具有实际计算公式和输入准入条件，属于尚未完成历史效果验证的研究规则。GET /market/research-score只读使用已经保存的事实，不访问上游或写入评分。收盘流水线另将结果保存为MARKET_V3。

## 五项公式

| 维度 | 0到20分公式 | 必须满足的输入 |
| --- | --- | --- |
| 指数趋势 | 收盘≥MA20、收盘≥MA60、MA20≥MA60、MA20上行，各5分 | 同日有效沪深300收盘、MA20/60及斜率；明确为指数代理 |
| 成交额与方向 | 指数收益非负时，20日成交额比≥1.2得20、≥1得15、否则10；指数收益负时，缩量得5、否则0 | 同日范围内连续20个完整市场截面及有效均额 |
| 均线广度 | 10×站上MA20比例＋10×站上MA60比例 | 两窗口均覆盖当日交易股票至少95%，分母必须有效 |
| 主题相对强度 | 20×有效主题RS20为正比例 | 完整主题清单、有效覆盖至少95%，实际样本范围明确 |
| 领先样本确认 | 20×领先名单中站上MA20且20日跑赢沪深300的比例 | 21个连续完整市场截面、同源因子、连续基准及至少95%全截面有效历史 |

领先名单按同一业务日可见的过去20日平均成交额前10%确定，按成交额降序、代码打破并列。不能拿自选名单代替全市场分母；历史不足、停牌缺口、缺因子或基准中间缺日都会阻止输出。名单、分母及确认数冻结在新市场观察的证据中，旧观察缺少该项时保持不足。

## 范围如何影响总分

分项同时返回实际范围和AVAILABLE、PROXY或INSUFFICIENT_DATA。沪深A股截面和披露同业样本可以展示各自原范围分数，但不会计入完整全A总分；指数趋势按模型明确定义使用沪深300代理，不声称是全部股票等权表现。

完整全A总分需要完整市场清单证明和五项合格输入。当前生产仅有沪深截面及固定披露样本，尚无完整全A清单证明，因此总分仍为UNKNOWN。此时属于明确输入范围不足，分项公式已经运行；不能通过改标签、补0或按可用维度放大得到总分。

只有全部准入条件满足才允许0到100总分及STRONG/POSITIVE/SIDEWAYS/WEAK/RISK_OFF状态。完整输入固定测试可得到100分，但这只验证公式和边界，不证明市场预测效果或收益。

## 实测完整清单核验

生产读取业务日实际不可变截面，逐来源核对清单、日期、重复证券、交易状态、价格/成交额、原文指纹和SSE/SZSE/BSE实际数量。FULL_A准入还须原文universeProof包含同日source、scope、completeRoster、三交易所声明、expectedCount、规范化排序成员名单的rosterSha256和公开HTTPS sourceUrl，且全部应有交易证券都有截面或明确停牌证据。没有完整声明时，全A分母保持未知，不拿已观察沪深数量替代。

页面和GET /market/coverage分别列出已测交易所数量及具体缺项。生产不再固定构造零覆盖布尔值，而是消费上述核验结果。当前供应商适配仍仅提供沪深清单，没有凭空加入北交所或完整主题，因此输入不齐时评级继续UNKNOWN。即使清单证明合格，各分项仍须满足自身范围和历史门槛，完整清单不会自动把披露主题样本升级成全市场主题。
