# 多周期持有与买卖研究

产品流程：洞察市场 → 产业链与机构预期 → 自选 → 完成数据同步 → 按周期研究行动 → 报告归档 → 后续跟踪与历史验证。页面入口见“帮助中心 → 使用说明”；名词和状态通过独立的“术语与状态”页面查询。

自选股点击“研究与买卖计划”进入个股默认页。`HOLDING_RESEARCH_V1`只读当前已保存的行情、因子、日历、财报和规则，不触发采集或交易、不读取个人仓位、不改写历史报告。历史日期查询为当前版本回顾，不能证明历史时点可得；冻结报告仍保存原始修订。

## 中期口径

使用本期因子锚点的同源复权价格。至少65个有效交易日，真正使用的窗口必须与权威日历（扣除同源明确停牌）相符；缺日、混源、重复、无因子或演示均保留不足。

- 回踩观察带：本期MA60上下各`max(MA60×1%, 近两月方法的前14期ATR×0.25)`。
- 原结构退出参考：此前60期最低价减`0.5×ATR`，不含本期K线；本期新低不会向下重设该参考。
- 建仓：收盘与MA20均≥MA60，MA60不低于5个交易日前，收盘在观察带内；观察带上沿到退出参考的正距离≤12%，且未触发减仓或退出组合。
- 加仓：沿用建仓条件，另要求前收≥前一日MA60、本期收盘≥MA60且当日成交额量比≥1。个人已有持仓、原逻辑和额度另外核验。
- 减仓：尚未突破此前60期高点、当前位于其99%以上，5日收益≥2%且独立5/20期成交额量比≤0.8。已越过前高时不外推更高卖价。
- 退出复核：收盘≤原结构退出参考；或收盘低于MA60且MA60低于5个交易日前。任一组合满足即先处理风险，并拦截新建/加仓。

12%、1%、2%及量比门槛均是明确但未验证的研究参数，不是个人亏损预算。MA60及观察带每日变化，必须使用对应日期的新数据复核。

## 长期口径与缺项

财报仅采用截止日16:10之前公开且已可用的版本；日期精度资料保守次日起可用，未来披露和未来修订不参与。期末距研究日超过200天时标出时效不足。利润和经营现金流、营收与利润同比、财报风险规则分别列出实际值；无记录或未完成核验保持未知，不能当作无风险。

MA250只是长期趋势复核价，不是合理估值或保证止损价。当前未接入可核验合理价值、安全边际和个人经营论点，长期建仓与加仓价格为空，并明确等待这些前提；不能以短线支撑或均线冒充长期合理买价。核心逻辑失效、估值假设被否定或个人原风险底线到达时，应执行原计划；系统不会声称已核实这些前提。

## 状态和阅读方式

每个周期给出当前判断、行动状态、观察价带、参考价准确用途、全部条件的实测值与要求、失效条件、证据与缺项。买入/加仓使用ALL；减仓风险使用ANY；`met=null`表示待核验，不等于未触发。行情条件满足后仍须核对个人前提，接口不提供券商委托。

界面在首屏展示周期与当前结论；展开次级说明可查看方法和失效前提。当前计划与冻结报告之间只提供明确跳转，不对旧报告追加新结论。无新表、无SQL迁移。

通用概念参考：[Fidelity技术分析](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/what-is-technical-analysis)、[Investor.gov订单执行与参考价格](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-14)。本产品窗口与参数自行定义，这些来源不代表认可本方法效果。
